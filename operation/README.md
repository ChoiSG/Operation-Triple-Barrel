# Operation

AdaptixC2 server configuration, BOF modules, and operational playbook for Triple Barrel.

## Contents

- `adaptix-profile-example.yaml`  - Adaptix server profile
- `adaptix-https-listener-example.json`  - HTTPS listener config
- `nginx-example.conf`  - Nginx reverse proxy for the teamserver
- `edrchoker-bof/`  - QoS-based EDR network throttling (BOF)
- `persistask-bof/`  - Scheduled task persistence via COM (BOF)
- `petitpotam-BOF/`  - MS-EFSRPC NTLM coercion (BOF)
- `smbtakeover-bof/`  - SMB takeover (BOF)
